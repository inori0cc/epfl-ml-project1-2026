# Original baseline evidence

Files in this directory are historical evidence for the original 32-bin model in `../models/`. Their recorded submission hash refers to the preserved `../submission_baseline.csv` (formerly named `submission.csv`). They do not describe the newer root submission.

The latest experiment and its verification are in `../optimization/results/`. Both experiments used the same stored split IDs. See the project README for the measured comparison and its limitations.
